## To execute the L2 gate (when `/dev/kvm` is granted)

```bash
# operator, once:
sudo setfacl -m u:xvysnya:rw- /dev/kvm            # session-limited
# or persistent: sudo usermod -aG kvm xvysnya && relogin

cd rust
cargo build -p agentkit-sandbox-guest --release --target x86_64-unknown-linux-musl
scripts/sandbox-image/build-guest-kernel.sh          # pinned, offline-capable with cache
scripts/sandbox-image/build-guest-rootfs.sh          # pinned, unprivileged
scripts/sandbox-image/assemble-registry.sh           # registry + manifest.json provenance
AGENTKIT_REAL_VM=1 cargo test -p agentkit-sandbox-worker \
  --features firecracker --test real_vm -- --nocapture
```

Optionally `AGENTKIT_SANDBOX_CGROUP_ROOT=<delegated subtree>` to exercise
cgroup enforcement (S19); without it the backend probe reports
`enforced:false` honestly and resource ceilings are not host-applied.

The L2 test asserts: pinned image digests enforced at provision, boot-nonce
channel association, real exec with captured stdout, **conclusive** stop
evidence from process observation, clean destroy with nothing retained.
