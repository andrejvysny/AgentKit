What the comparison found

Ordered by how much each one costs if left alone. The first two must be handled inside the merge. The rest shape the roadmap.

HIGH

Master's native lane has no home, and one guard would vanish silently

7.8k lines (native_executor.rs, native_bridge.rs) were added to a crate that arch/cleanup deleted. Session admission validates the frozen native stanza inside #[cfg(feature = "http")]. agentkit-sessions has no such feature, so a mechanical merge compiles the typed validation out and falls back to a key whitelist.

HIGH

The composition root is closed

AgentRuntimeBuilder::build creates exactly one executor map entry, chat.turn, and refuses to build without a default HTTP provider. A consumer turn kind such as onemind.chat, or the NativeDispatchExecutor that routes between model loop and Claude Code, can only be wired by building AgentHost by hand. That is the situation P1 was meant to end.

HIGH

Persistence is behind a port for one context out of four

Engine is clean. Sessions, chat and agents carry an allowlisted edge to the store, and sessions::store_aliases pins the engine generics to SqliteStore. The gate does not look at adapter-to-adapter edges, so mcp → store and http → store pass unseen.

HIGH

Governance has ports in layer 2 and its implementation inside chat

Staging, durable execution receipts, write policy and proposals sit in chat::governance. They use almost nothing else from chat. With two execution owners, the native broker's authority needs the same receipts and approvals, and it must not depend on chat to get them.

MEDIUM

The static-state rule measures the wrong thing

34 of the 58 allowlisted statics are immutable lazy constants: regexes, lookup tables, parsed schemas. Seven real mutable statics are invisible to the script (three AtomicU64 counters, a Notify, two Once, one aliased Mutex), as are four thread-locals. The allowlist can never reach zero in this form, and it hides what it was written to catch.

MEDIUM

Three process supervisors, three private-directory writers

After the merge, process-group kill logic exists in toolpacks-coding, in claude/transport.rs and in lsp. Private run directories are created in the same three crates. Open Plane items AGENTKIT-138 and 143 ask for more of this code. It belongs in one place.

MEDIUM

Every wire change is edited three times

Rust DTOs, the schema bundle (130 schemas on one line) and TypeBox are each written by hand and held together by parity tests. The native execution target is not in the bundle at all, so TypeScript callers pass it as untyped JSON.

MEDIUM

The Node binding kept its shape

napi has a 2,237-line service.rs, 24 #[path] attachments, seven mutable registries and no Rust tests. It is the largest remaining block of rule exceptions outside toolpacks-coding.

LOW

Naming and bookkeeping

Two ADRs are numbered 0021. "Native" now means two things: the Rust engine behind @agentkit/native and a vendor agent runtime in agentkit-native. The agentkit facade has a feature called runtime that does not include agentkit-runtime. The rule "the allowlist only shrinks" has no provision for merging trunk. Status 12 Nov: the ADRs are renumbered (0025 Claude contracts, 0026 execution owners), the facade is folded into agentkit with features claude/core, and R13 codifies the merge provision.

Revised target: two execution owners, one composition root

The six layers stay. What changes is layer 2: next to the model loop in agentkit-core sits agentkit-native, the ports for a vendor agent runtime. Each admitted turn picks exactly one of the two. Everything the native lane needs follows the same hexagonal pattern as the rest: a context that owns its ports, adapters that implement them, and the runtime as the only place that names concrete types.

Ports: what exists and what is missing

A context declares the trait and owns the records it speaks in. Work that must be atomic across aggregates is a dedicated port method, as settle_session already is. Contexts stay generic over the repository; composition picks the store. The native lane keeps all of its ports in the layer-2 crate agentkit-native, beside the backend ports, so the executor's SQLite-backed unit tests need no dependency cycle.

descriptor.rs and check_frozen merge without conflict and still carry #[cfg(feature = "http")]. Both become unconditional calls to agentkit_native::validate_frozen_stanza, and the not(feature = "http") fallback is deleted. This is what master does whenever the native lane is compiled in.

SendInput, FollowUpInput and SteerInput gained a field, so call sites written on arch/cleanup need frozen_payload: None. Contracts: Rust owns the wire, by hand

ADR 0022 made Rust the authority, as planned. The planned mechanism did not survive contact: schemars 1.0.4 emits a different JSON Schema draft and nullable shape, and the DTOs carry none of the 636 constraints the bundle states. The result is correct and tested, and it costs three synchronized edits per wire change. The follow-up is to make the schema the one edited artifact.

Roadmap: merge, land, then small steps on master

Columns show order, not calendar time. The merge is one goal for the coding agent. Once it is green, PR #4 lands and the cleaned structure becomes the trunk. Everything after that is a short branch off master, so the next Claude Code fix is written once, in its final place.

Risks and how each is contained

HIGH

Losing hardened behaviour while porting the native lane

The Claude backend went through five review rounds and a live qualification. The merge moves its files without editing their logic, keeps all 273 tests, and replays the recorded live fixtures. The live tests stay ignored by default, and the owner re-runs them against the real CLI before PR #4 lands.

HIGH

A merge that leaves arch/cleanup half-done

All iteration happens on an integration branch. arch/cleanup is touched once, by a fast-forward to a merge commit built from a tree that already passed every gate. If the agent stops halfway, the branch behind PR #4 is unchanged.

HIGH

Breaking lease fencing during the repository split

Unchanged from the first plan and still ahead. Fenced writes and the one-transaction settle stay dedicated port methods. The zombie, crash and stale-lease tests move into the conformance suites before any caller switches.

MEDIUM

Master keeps moving

Nine Claude Code items are open in Plane. Until PR #4 lands, each fix on master has to be carried across the host split again. Hold them, or land them on the integration branch, and land PR #4 as soon as the merge is green.

MEDIUM

An unattended agent drifting off the plan

Both runbooks have numbered stages with a check at the end of each, a progress file that survives context compaction, a list of forbidden shortcuts, and a rule to stop and report instead of improvising when a check fails twice.

MEDIUM

Rust consumers of the native lane

Code that wired the native lane against master imports agentkit_host::native_executor and native_bridge. Those paths become agentkit_native_exec and agentkit_native_broker. The changelog entry for the merge lists the mapping, and C1 replaces hand wiring with the builder.

LOW

Build time and disk use

Five more crates, one of them a 9k-line driver. Heavy dependencies stay in leaf adapters. Check free disk before long builds and clear rust/target/debug/incremental under 30 GB free.

Decisions

Settled with the owner on 2026-11-11, in addition to the earlier ones (Rust contract authority, TypeScript backend deleted, per-context repositories, typed boundaries, Unix first with Windows compiling, no host shim).
