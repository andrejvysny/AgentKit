# Sandbox runtime — S01–S20 enforcement-owner map

Code-coupled companion to `docs/specs/sandbox-runtime.md` §3.5 and ADR 0021.
Every mandatory invariant lists its enforcing component(s), the concrete
code, and the test/evidence that demonstrates it. "M2/M4" marks invariants
whose remaining enforcement lands with the named milestone (never implied
done before its gate).

Owners: **Host** = AgentKit host (Rust run/task authority, `rust/crates/*`,
M2/M3/M6 work); **Worker** = `agentkit-sandbox-worker` daemon;
**FC** = `agentkit-sandbox-worker-fc`; **Guest** = `agentkit-sandbox-guest`;
**Pack** = `toolpacks-coding` routing; **Images** = `rust/scripts/sandbox-image`.

| ID | Invariant (abridged) | Owner(s) | Code | Evidence |
| --- | --- | --- | --- | --- |
| S01 | One tenant/sandbox/generation/policy digest + bounded reservations per VM | Host, Worker | `sandbox-contracts/src/api.rs` `VerifiedLaunchSpec`; `worker/src/registry.rs` reserve; `service.rs` CreateVm envelope/launch cross-check + `check_generation` pins EVERY envelope operation (create/stop/destroy/inspect/writer-acquire) to the registry generation -- stale-generation envelopes die `StaleGeneration`; every boot is a strictly-next generation, never in-place reuse | `worker/tests/lifecycle.rs` (create/stop/destroy, restart reboot to next gen, generation-skip refusal), `worker/tests/quotas.rs`, `worker/tests/fuzz_dispatch.rs` (generation-bump splice refused) |
| S02 | Tenant from authenticated context only | Worker, Host | `service.rs` envelope cross-check (tenant/principal/sandbox/generation agreement); `transport.rs` `SO_PEERCRED` uid allowlist | `worker/tests/tenant_denial.rs` (foreign ≡ missing, no existence leak), `uds_peer_auth.rs` |
| S03 | No host dirs/sockets/devices mapped into guests | FC, Guest, Images | `worker-fc/src/backend.rs` drives = derived rootfs+data only, **no `/network`, no host shares**; `scripts/sandbox-image/guest-init.sh` mounts only proc/sys/tmp/`/dev/vdb`; kernel config strips 9p | `worker-fc` `jailer_ids_are_allowlisted_charset` + path-derivation tests; `guest/tests/fsops_hostile.rs` |
| S04 | No guest NIC; package access broker-only over vsock | FC, Guest, Images | `backend.rs` never calls `/network`; `probe.rs`; kernel `VIRTIO_NET` off; `guest/src/server.rs` `BrokerRequest`→`sandbox_capability_unsupported` until M4 | kernel-script hard assertion `!CONFIG_VIRTIO_NET`; L2 doc; fake broker tests |
| S05 | Fail closed without verified virt/entitlements; never substitute | FC, Worker | `probe.rs` (KVM open+ioctl, versions, fail-closed `Probe` errors); `backend.rs` provision gate `IsolationUnavailable`; CLI `--backend firecracker` without feature ⇒ `CapabilityUnsupported`, never fake | `probe.rs` tests, `backend.rs` tests, worker CLI fail-closed test |
| S06 | All sandbox-bound tool I/O via worker; no host fallback ever (incl. timeouts/errors) | Pack, Host | Pack tool dispatch behind `target=vm_sandbox`; host `SandboxWorkspaceIo` client (M2); no `std::process`/`std::fs` path reachable from vm_sandbox session | M2: `toolpacks-coding/tests/no_host_fallback.rs` (gate for M2), grep-enforced CI check |
| S07 | Existing Host authorization + immutable fenced command identity; post-dispatch failure = **uncertain** | Host, Worker | Host `admit_execution` receipts (ADR 0019) + `ExecRequest.request_digest`; journal `exec_admitted→…→cleanup_verified`; unknown completion never auto-replayed | `worker/tests/exec_flow.rs` (digest forgery refused, replay/conflict semantics), `journal_replay.rs` |
| S08 | Worker/guest cannot mint or widen grants; subagent ⊆ parent∩role∩tenant∩session | Host, Worker | Host mints `WorkspaceGrant` (`session.rs` scaffold + `subagent.rs` derivation: child task authority is capability/path **subset only**, `SandboxManage` never delegable, reviewer pinned read-only); worker **only verifies** (`service.rs` grant checks, `grant.rs`); the only worker-minted material is the writer-admission token, derived server-side from the authenticated envelope + durable journal, never accepted as input; guest never sees grant material, only per-request decisions | `exec_flow.rs` grant-path denial; `sandbox-host/src/subagent.rs` narrowing/identity/cancellation tests; `sandbox-host/tests/subagents_worker.rs` (live worker: child scope enforcement, reviewer read-only, cancellation) |
| S09 | One admitted writer; overlapping guests/disk mounts and stale generations refused | Host, Worker, FC | Worker is the authoritative admission: `WriterAcquire` RPC bumps a per-sandbox epoch (`registry.rs` `acquire_writer`/`verify_writer`, durable `WriterAcquired` journal record), mutating grants (`SandboxWrite`, `ArtifactImport`) must carry the live current-epoch token of the acting task — missing/stale-epoch/foreign-holder/expired all `PolicyDenied`, stale generation `StaleGeneration`; last admission wins, superseded grants die deterministically; `worker-fc/src/disk.rs` `DiskClaim` flock blocks double mounts; host bridge `WorkerClient::acquire_writer` mints for tasks and injects `PackEnv::vm_writer_lease` | `sandbox-worker/tests/writer_lease.rs` (no-lease refusal, supersession, holder/gen/expiry tampering, journal-durable admission across restart, exec ungated); `sandbox-host/tests/subagents_worker.rs` parent-vs-child contention on the live worker |
| S10 | Host-only creds stay host-only; guest env = explicit allowlist | Guest, contracts | `grant.rs` `GuestEnvironment` bounded name/value allowlist; `guest/src/supervisor.rs` env exactly the six mandated vars, never inherited | `guest/tests/exec_supervisor.rs` env assertions |
| S11 | OCI content never executes/trusted on host; conversion itself isolated | Host, Images | M4 importer: digest-pinned fetch, layer extraction inside a dedicated builder VM, path/whiteout policy; today only admin-pinned `registry/` images boot (`backend.rs` digest verify) | M4 gate: import tests inside builder VM; today `disk.rs` digest mismatch tests |
| S12 | Imports/exports verify paths, types, sizes, digests, grant; no writes to original user paths | Worker | `service.rs` staging begin/chunk/commit (chunk digest verify, size caps), export gather manifest | `exec_flow.rs` staging digest-mismatch, chunk overrun |
| S13 | Tenant quotas incl. vcpu/RAM/disk/pids/VMs/wall-time/logs; transactional fenced reservations | Worker, Host | `registry.rs` `QuotaCeilings` + reserve/release fencing; per-command rlimits (`supervisor.rs`) + FC cgroups (`worker-fc/src/cgroup.rs`) | `quotas.rs` (3: exhaustion with zero partial effects, release, stale release) |
| S14 | Termination ≠ rollback proof; unknown execution/cleanup quarantines resources; restart recovery never optimistic | Worker, FC | `backend.rs` terminate conclusive only via process evidence; `service.rs` inconclusive ⇒ `Quarantined`, disks/pids retained; `guest supervisor.rs` descendant sweep → `Uncertain`; journal replay marks launched VMs `physical=Unknown`+quarantined, and `reconcile_replayed` (auto on host `Hello`, §11.4) must independently prove state: survivor reclaimed with durable `VmStopped` evidence, unprovable stays quarantined, only conclusive evidence clears it (`registry.clear_quarantine`) | `lifecycle.rs` inconclusive-stop quarantine/retain + `worker_restart_reconciles_then_reboots_new_generation` (pre-reconcile refusal → survivor terminated → gen-2 reboot); `soak.rs` crash phase; `fault_injection.rs`; `guest/tests/exec_supervisor.rs` group-kill/uncertain |
| S15 | Persistent sandboxes: no tenant/image/policy transfer; fenced verified deletion | Host, Worker | persistent flag + generation pinning in registry; destroy requires verified termination receipt | `lifecycle.rs` destroy-receipt assertions; M3 store tests |
| S16 | Every frame/path/env/log length- and time-bounded, versioned, duplicate-suppressed | contracts, Worker, Guest | `protocol.rs` framed codec + limits; `worker/src/transport.rs` SequenceGuard/DuplicateTable/deadline; guest `server.rs` same guards; `limits.rs` caps everywhere | contracts protocol tests; transport unit tests; guest handshake tests |
| S17 | Guest artifacts/streams are untrusted data; cannot authorize or inject host control | Worker, Host | service maps guest `Failed` codes to fixed contract codes; digests re-verified worker-side (`FsWrite` readback, staging hash); no guest-authored object reaches host policy | `exec_flow.rs` guest-claim overrides refused; `journal_replay.rs` conservative replay |
| S18 | Audit records IDs/digests/decisions; excludes provider keys, bearer secrets, uncontrolled file content | Worker, Host | journal JSONL records ids/digests only; `transport.rs` audit lines for peer rejections; content stays in content-addressed private store | journal record type definitions (no free-form payload fields) |
| S19 | Portability claims require real-host tests or reported unsupported; no silent skips | all | `BackendCapabilities {supported,enforced,evidence}` (`api.rs`, `probe.rs` cgroup honesty); L2/L3 harnesses print `NOT RUN <reason>` and never fake pass | `docs/baseline/sandbox-l2-2026-11-08.md`; probe tests; `real_vm.rs` gate |
| S20 | No privileged daemon accepts raw command paths, host mounts, extraction paths, or caller hypervisor sockets | Worker, FC | `WorkerConfig` CLI/env admin-only (`config.rs`); all VM paths derived (`service.rs gen_dir/jailer_root`, `backend.rs sandbox_dir`); wire never carries host paths | `config.rs` required-flags tests; derived-path parity tests (both crates); `exec_flow` wire-path rejection |

Review rule: any change to a listed code file MUST update its Evidence cell
in the same PR; a milestone gate MUST NOT pass with an empty Evidence cell
for an invariant it claims.
